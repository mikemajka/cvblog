### **Autonomous Robot Control System**

Designed a complete robot control system including sensor fusion, real-time motor control, and PCB integration for autonomous navigation. Built firmware for the microcontroller and coordinated communication between the sensing, actuation, and power systems.

#### Key Features
- Custom PCB layout and routing for motor drivers and sensor interfaces.
- Real-time control loops running on an FPGA-friendly microcontroller.
- Modular design for easy expansion and testing.
